## 1. 项目简介

本项目使用两套Amazon公开数据，开展商品评分分布、评论情感与主题探索，以及推荐模型离线评估，并形成商业分析报告、演示文稿和交互式仪表盘。

两套数据分别分析，不直接合并。评分记录数量不等同于销量，离线推荐指标不代表实际线上收益。

## 6. 主要实验口径

推荐实验以2014年1月1日零时（UTC）划分训练与测试数据，将4～5星定义为正反馈。

热门基线与ItemCF＋热门补齐使用相同的评估用户、候选商品范围和评价口径。Recall@10、NDCG@10先按用户计算，再对评估用户取平均。

商品覆盖率为全部推荐列表涉及的不同商品数除以候选商品数，不代表单个用户的推荐多样性。

LDA四主题方案用于简化的探索性展示，不表述为一致性得分最高或统计意义上的最优方案。

## 7. 主要结果

当前报告对应的推荐评估结果如下：

| 指标 | 热门基线 | ItemCF＋热门补齐 |
|---|---:|---:|
| 平均用户Recall@10 | 1.6177% | 1.2537% |
| 平均用户NDCG@10 | 0.007540 | 0.005961 |
| 商品覆盖率 | 0.00419% | 54.14294% |

评估用户数为870,128，候选商品数为406,064。

当前ItemCF＋热门补齐扩大了推荐商品范围，但准确性低于热门基线。该结论仅适用于当前数据划分、模型和参数设置，不代表所有协同过滤方法均弱于热门推荐。
